隐私政策

三才防火墙（SancaiFirewall）· 生效日期：2026-11-26 · 版本：0.9.2
一句话概括：本软件是运行在你自己电脑上的本地安全工具。规则、审计记录与密钥全部只存放在本机， 开发者不设立服务器、不收集、不上传、不查看你的任何网络数据与使用记录。

一、我们收集什么

不收集。本软件不包含账号系统，不需要注册或登录，不接入用户行为分析、广告或统计 SDK， 不采集设备标识、硬件指纹或崩溃日志。开发者不会收到你本机的流量记录、规则配置、审计链或使用时长。

二、数据保存在哪里

所有运行期数据保存在本机数据目录：

  • 默认位置：%ProgramData%\SancaiFirewall\data
  • 绿色版：解压目录下的 data 文件夹，随目录移动，不写入系统用户目录

该目录内的文件及用途：

  • rules.json — 你编写或导入的防护规则，可编辑
  • seal.key — 本机印信密钥，用于审计记录的封印校验，每台机器各不相同
  • users.json — 本机操作口令（以哈希形式保存，不含明文）
  • audit_chain.jsonl — 审计链，记录规则变更与判决事件，用于取证与自证
  • evolution_ledger.json — 版本进化台账与律缺统计
  • logs\ — 服务运行日志

上述文件不会离开你的电脑。卸载软件不会自动删除数据目录；如需彻底清除，请手动删除该目录。 删除 seal.key 与 audit_chain.jsonl 会使既有审计链失去校验能力，请先备份。

三、本软件处理的网络信息

作为防火墙工具，本软件需要在本机处理网络连接信息以做出放行或拦截的判决，处理范围严格限定为连接元数据：

  • 源地址、目的地址、源端口、目的端口、协议类型、字节数
  • 连接发生时间与命中的规则编号

本软件不解析、不记录、不落盘通信内容正文，不对加密流量做解密，不保存网页、邮件、消息或文件内容。 可选的 pcap 接入仅在你自己手动启用时工作，用于读取本机 pcap/pcapng 文件或实时抓包做规则回放， 其提取结果同样只有上述元数据。这些信息只写入本机审计链，不上传。

四、联网与第三方服务

本软件默认可完全离线运行，仅在以下情形可能发起一次网络请求，且均由你主动触发：

  • 数字签名时间戳：当你选择对安装包或更新包签名时，安装器会向公共时间戳服务 （timestamp.digicert.com）提交该文件的哈希摘要以获取可信时间戳。提交内容为摘要值， 不包含文件正文、规则内容或任何个人信息。若不需要可信时间戳，可跳过签名环节，安装流程全程不联网。

本软件不连接开发者服务器，不含自动更新回传、云端情报订阅或远程控制通道。上述第三方服务的处理行为适用其自身隐私政策。

五、系统权限说明

  • 管理员权限：用于读取与下发 Windows 防火墙规则、安装并管理守护服务。非管理员运行时功能受限，但不会越权。
  • 守护服务：SancaiGuardService.exe 作为 Windows 服务常驻，负责在后台维持规则生效并写入本机审计链，不产生对外通信。
  • 开机自启：安装时按你的选择注册，可随时在系统服务管理器中停用或卸载。

六、你的权利

由于数据全部保存在你本机，你可以随时自行查看、导出、修改与删除：直接操作数据目录，或在软件内管理规则与审计记录。 开发者不持有你的数据，因此不存在开发者侧的查询、更正或删除动作；如需彻底清除，删除数据目录即可。

七、儿童隐私

本软件是面向成人用户的系统安全工具，不面向儿童设计，也不会有意收集 13 岁以下儿童的任何信息。

Privacy Policy

SancaiFirewall · Effective: 2026-11-26 · Version: 0.9.2

Summary

SancaiFirewall is a local desktop security tool. All rules, audit records and keys stay on your own computer. The developer operates no server and does not collect, upload or access your network data or usage records.

Data storage

Runtime data is stored locally at %ProgramData%\SancaiFirewall\data (portable edition: the data folder inside the program directory). Uninstalling does not delete this folder; remove it manually for a full wipe.

Network information processed

To decide allow or block, the app processes connection metadata only: source/destination address and port, protocol, byte counts, timestamp and matched rule id. Message payloads are never parsed, logged or stored. Nothing is transmitted off your machine.

Third-party services

If you choose to sign a package, its file hash digest is submitted to a public timestamp authority (timestamp.digicert.com) to obtain a trusted timestamp. No file content or personal data is sent. The app runs fully offline when signing is skipped.
